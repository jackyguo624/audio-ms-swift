# FireRedASR-LLM-L 在 AISHELL-1 上的 SFT 退化 case 分析

对齐同一完整测试集的 7,176 句、104,765 个参考字符后，原始模型到本次单 epoch SFT 的 CER 从 **0.7674% 升至 0.8113%**：804 → 850 个字错误，净增 46（+0.0439 个百分点，相对 +5.72%）。变化以局部字词替换为主；同时存在可见的内容变化和书写/参考口径敏感样例。

本分析复用已经配对验证的原始/SFT 预测，不改变评分口径。全部句子重新做独立 Levenshtein DP 核对；人工浏览全部 105 条退化和 72 条改善，详细样例标签覆盖 12 条退化、5 条改善及 7 条额外口径敏感候选。标签可重叠，未估计全局类别占比。本次未听音，也未审定参考文本真伪。

## 全量统计

| 指标 | 结果 |
| --- | ---: |
| 字错误增加的句子 | 105；逐句净增加合计 129 |
| 字错误减少的句子 | 72；逐句净减少合计 83 |
| 字错误数相同的句子 | 6,999 |
| 规范化输出改变 | 191 句，其中 14 句错误数不变 |
| 规范化输出完全不变 | 6,985 句（97.34%） |
| 原来全对、SFT 后变错 | 84 句 |
| 原来有错、SFT 后全对 | 56 句 |
| 两侧均有字错 | 594 句 |
| 句错误率 SER（至少一个字错） | 9.0580% → 9.4482% |

`129 − 83 = 46`；这里的 129/83 是各句错误差的正负部分。同一句可能既修复旧错又引入新错，不能将它们称作所有字符错误事件的新增/修复总数。85 条退化句只多 1 个错误，20 条多 2～4 个错误；最大单句增量为 4。所有解码均无截断；105 条退化句的规范化输出长度相对原始模型最多增加 1 个字符。

| 字级操作 | 原始 | SFT 后 | 净变化 |
| --- | ---: | ---: | ---: |
| 替换 S | 689 | 733 | +44 |
| 删除 D | 60 | 58 | −2 |
| 插入 I | 55 | 59 | +4 |
| 合计 | 804 | 850 | +46 |

主评分采用既定的替换、删除、插入优先级。原始/SFT 分别有 37/39 句存在多条最优对齐路径；换另一优先级后，总错误及 S/D/I 净变化仍一致，个别字符的定位与混淆统计仍应按声明的对齐规则解释。

- 她/他、地/的属于需要文字语境的写法选择。当前 CER 精确按字符计错，不应自动将其解释为听错了发音。
- 二三岁→二十三岁多一个十，按本次不做 ITN 的规则计插入。需要听音和检查数字转写规范，才能判定是否属于实际识别退化。
- 李彬彬→李冰冰、鉴借→借鉴、重监护室→重症监护室是待核查候选：输出看起来通顺或熟悉，仍不能据此宣布参考有错或模型纠错成功。
- 额外案例 `BAC009S0901W0187` 显着→显著、`BAC009S0907W0425` 报导→报道、`BAC009S0915W0466` 账户→帐户各产生一错。NFKC 不把这些词形自动合并；这是已声明评分规则的敏感性，尚不能称为评分实现 bug。
- 券/劵在参考中存在两种写法：`BAC009S0769W0187` 债券→债劵使 0→1；`BAC009S0770W0215` 两处债券→债劵却使 2→0，因为该句参考就是劵。这说明计分改善也不一定意味着语义或实际发音识别改善。官方参考保持原样，不能根据测试结果临时宽松改分。

原始和规范化后的输出变化句数均为 191，没有仅靠标点或空白变化造成的退化；人工浏览也未发现这 105 条退化是由阿拉伯数字输出格式切换引起。

## 集中度与不确定性

实际测试集包含 20 个说话人 ID 分组，13 组净错误增加、7 组减少。净增加最多的四组如下：

| 说话人 ID 分组 | 测试句数 | 原始字错误 | SFT 字错误 | 净变化 |
| --- | ---: | ---: | ---: | ---: |
| BAC009S0915 | 363 | 37 | 48 | +11 |
| BAC009S0905 | 360 | 30 | 40 | +10 |
| BAC009S0765 | 361 | 26 | 35 | +9 |
| BAC009S0913 | 363 | 49 | 58 | +9 |

这四组共 1,447 句，净增 39 错；其余 16 组合计净增 7 错。这里按说话人 ID 分组的文本内容也不同，不能由此断言某种声音或口音导致退化。去掉任意一组后，总净错误仍增加 35～51，变化并非由单个说话人独自造成。

固定两个 checkpoint，对完整配对单位重采样 20,000 次，CER 差统一定义为 `100 × Σ(SFT错误 − 原始错误) / Σ参考字数`：

| 重采样单位 | seed | CER 差的 95% percentile 区间（百分点） |
| --- | ---: | ---: |
| 句子（7,176 个单位） | 20261012 | +0.0124 ～ +0.0766 |
| 说话人 cluster（20 个单位） | 20261013 | +0.0077 ～ +0.0818 |

两种区间均在零以上，支持固定模型在此测试样本分布上的小幅退化。它们是测试样本重采样敏感性，不是多次训练的方差，也不能解释训练原因。

## 对训练原因的解释边界

现有证据支持“局部字词选择发生变化，损失略大于收益”。本次同时更新了 LLM LoRA、音频编码器和投影层，且使用最终 1 epoch checkpoint；不能仅从案例断言是 LLM 遗忘、音频侧受损、学习率过高或过拟合。

要定位具体模块，需要受控的冻结/更新音频侧消融、开发集 CER 的 checkpoint 比较和多个训练 seed；要区分转写写法与实际听错，需要回听并核对候选参考。这些是当前结论的验证边界，不改变已报告的官方固定口径 CER。

完整逐句配对、105 条退化 TSV、72 条改善 TSV、源文件哈希及独立审核保存在本地 `output/asr_benchmark_20261010/case_analysis_20261012/`。公开的 [机器可读分析](firered-aishell-case-analysis-20261012.json) 保存统计、bootstrap 参数、真实样例、验证边界和输入哈希；整体对比见 [ASR Benchmark](asr-benchmark-20261010.md)。

后续已补做 [组件替换与原因分析](firered-aishell-regression-causes-20261012.md)：只换 LLM LoRA 复现了 105 条退化句中 96 条的完整 SFT 输出。该干预定位现有权重的影响组件，尚不等价于冻结模块重新训练的结果。
